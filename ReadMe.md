# 30 Websites in 30 days challenge

This is my personal 30 Websites in 30 days challenge

## Challenge Details

The challenge: 
- Complete 1 layout out of the 5 for the day 
- Complete layout using HTML5, CSS3 and Vanilla Javascript - no third party libraries
    - Webpack is allowed if desired, though may be overkill for a 3 file project.
    - Ideally, each layout will have an outer container that uses css grid for main layout. 	
- Responsive design, breakpoints at 480, 768, and 1024 at a minimum
- Each page should have a footer, even when not displayed in image


## Challenge Assets

Prompts:
- Prompts were created by Perplexity.ai
- Each Prompt includes a positive prompt, negative prompt and name.

Images:
- For image generation, Flux Schnell was used with 1920x1080 output size.
- 5 images were created per Prompt

Folder Structure:
- Main assect folder has 150 pictures, complete list of prompts, and Workflow json used.
- Each day folder has an asset folder with 5 images and a name.txt file.
